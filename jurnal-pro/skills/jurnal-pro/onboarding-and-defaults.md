# Onboarding dan default

Dipakai pada tahap INTAKE. Tampilkan formulir di bawah **utuh dalam satu respons**. Pada tahap EXECUTE, berkas ini dipakai untuk default dan untuk membaca isian yang sudah ada.

## Formulir

> **Temukan jurnal yang tepat untuk manuskrip Anda**
> Isi yang Anda ketahui saja. Isian yang kosong memakai default di bagian bawah.

### 1. Naskah (pilih salah satu)

- [ ] Unggah berkas manuskrip (PDF, DOCX, atau TXT)
- [ ] Tempel teks: judul dan abstrak lengkap
- [ ] Hanya topik: judul atau topik singkat (hasil akan lebih terbatas)

### 2. Identitas naskah

- **Judul:**
- **Abstrak atau ringkasan** (idealnya 150–300 kata):
- **Kata kunci** (3–6):
- **Bidang atau subbidang** (opsional; akan diinferensi jika kosong):
- **Jenis artikel:** [ ] Artikel riset [ ] Tinjauan pustaka [ ] Studi kasus [ ] Lainnya: ____
- **Bahasa naskah:** [ ] Indonesia [ ] Inggris [ ] Lainnya: ____

### 3. Preferensi (opsional)

- **Bahasa jurnal:** [ ] Sesuai bahasa naskah [ ] Inggris [ ] Indonesia [ ] Apa saja
- **Indeks yang diutamakan:** [ ] Scopus [ ] Web of Science [ ] DOAJ [ ] SINTA [ ] Tidak ada preferensi
- **Akses terbuka:** [ ] Wajib open access [ ] Boleh hybrid atau berbayar [ ] Tidak masalah
- **Batas APC maksimum:** ____ (mata uang: ____). Kosongkan jika tidak ada.
- **Batas waktu proses atau tenggat:** ____
- **Jumlah rekomendasi:** ____ (default: 5)
- **Konteks geografis atau penerbit** (opsional): ____
- **Catatan lain** (mis. jurnal yang pernah menolak naskah serupa, atau jurnal yang ingin dihindari): ____

## Default untuk isian yang tidak diisi

| Isian | Default | Catatan |
| --- | --- | --- |
| Jumlah rekomendasi | 5 | Minimal 3 jika kandidat aman terbatas; jelaskan kekurangannya |
| Bahasa jurnal | Sesuai bahasa naskah | Jurnal bilingual boleh |
| Indeks | Scopus atau Web of Science diutamakan; DOAJ sebagai pelengkap; SINTA dicantumkan bila relevan | Status diverifikasi di sumber resmi |
| Akses terbuka | Tidak wajib; hybrid boleh | Biaya OA ditampilkan jika ada |
| Batas APC | Tidak dibatasi | Tampilkan semua biaya |
| Waktu proses | Tidak ada batas | Tampilkan estimasi resmi dan empiris |
| Metrik | SJR, CiteScore, atau JIF bila tersedia, disertai tahun | Tidak dipakai untuk peringkat utama |
| Konteks geografis | Tidak dibatasi | |
| Tanggal akses | Tanggal hari ini | Berlaku untuk semua status dinamis |
| Format keluaran | Laporan sesuai `output-contract.md` | Termasuk berkas template dan author guidelines untuk jurnal final |

## Aturan pengisian

- Ekstrak isian dari manuskrip atau pesan pengguna lebih dulu. Jangan menampilkan ulang isian yang sudah terisi.
- Catatan lain, seperti jurnal yang pernah menolak naskah, dipakai untuk menghindari pengulangan. Itu tidak cukup menjadi alasan mengeluarkan jurnal tanpa bukti.
- Jika klarifikasi diperlukan di tahap EXECUTE, tulis **satu** blok pesan dengan paling banyak tiga pertanyaan berpoin.
